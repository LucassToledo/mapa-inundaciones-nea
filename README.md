# Mapa de inundaciones Chaco y NEA

Mapa abierto que reúne en una pantalla el agua detectada por satélite (Copernicus), las alturas de los ríos del INA, las alertas del SMN, la prensa y los videos con fecha. Creado por [@eltiolucas.ia](https://www.instagram.com/eltiolucas.ia/).

- `web/`: el sitio y su instalación (ver [web/README.md](web/README.md)).
- `docs/`: documento explicativo (`documento-mapa-inundaciones.pdf`) y sus capturas.
- `video/`: script que genera el video explicativo.
- `investigacion/`: documentos de investigación y [plan de mejora](investigacion/10-plan-de-mejora.md).

Repositorio: https://github.com/LucassToledo/mapa-inundaciones-nea
